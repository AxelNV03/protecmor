1️⃣ Iniciar Proyecto usando docker
Windows

    1.  Abre "Activar o desactivar las características de Windows".
        Marca las siguientes opciones:
            1.1 Plataforma de máquina virtual (Virtual Machine Platform)
            1.2 Subsistema de Windows para Linux (WSL)
        Haz clic en Aceptar y reinicia tu computadora.

    2. Instalar Docker Desktop
        Ejecuta el instalador y sigue los pasos.
        Al finalizar, abre Docker Desktop y regístrate o inicia sesión. Cierra La app

    3. Abrir una Terminal de powershell o CMD y navegar hasta la raíz del proyecto.
        Dentor Ejecutar:
            docker-compose build app
        Esperas a que se construya el contenedor.
        verificas con:
            docker images
    4. levantar contenedores
        docker-compose up -d
    borrar los contenedores
        docker-compose down -v


    5. verificar que esten corriendo
        docker-compose ps

Con los contenedores levantados ya solo iniciar con
docker-compose start

Cuando acabes de trabajar usas 
docker-compose stop
y actias con start cuando quieras retomar el proyetocto

Para acceder a la terminal del proyecto usas
docker-compose exec app zsh
