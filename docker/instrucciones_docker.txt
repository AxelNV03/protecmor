1️⃣ Prerrequisitos
Windows
    Instalar Docker Desktop: https://www.docker.com/products/docker-desktop
    Habilitar WSL2 si estás en Windows 10/11 (Docker Desktop lo pide).

Linux (Arch, Ubuntu, Debian, Fedora…)
    # Instala Docker y Docker Compose
    sudo pacman -S docker docker-compose       # Arch
    sudo apt install docker docker-compose     # Ubuntu/Debian
    sudo dnf install docker docker-compose     # Fedora
    
    sudo systemctl start docker.service

Mac
    Instalar Docker Desktop: https://www.docker.com/products/docker-desktop
    Asegurarse que Docker y Docker Compose estén accesibles en la terminal.

2️⃣ Clonar el proyecto
git clone <tu_repo_git>
cd <nombre_del_proyecto>

3️⃣ Construir y levantar los contenedores
docker-compose build --no-cache
docker-compose up -d


4️⃣ Inicializar Laravel y la base de datos

Dentro del contenedor app:
# Abrir bash en el contenedor
docker exec -it protecmor-app-1 bash
# Recargar tus funciones del .bashrc
source ~/.bashrc
# Inicializar proyecto Laravel y base de datos
start       # tu función start hace todo: composer install, npm install, migraciones, seeders

Alternativa rápida para solo resetear DB:
db_reset

5️⃣ Acceder al proyecto

Laravel: http://localhost:8000
Vite (hot reload, desarrollo): http://localhost:5173


7️⃣ Tips y recomendaciones

Siempre usar docker-compose down cuando termines, para limpiar contenedores.

Si cambias .env o dependencias, vuelve a correr:

docker-compose build --no-cache
docker-compose up -d


En producción, compila los assets con:

npm run build


y no dependas del servidor de Vite (npm run dev).

Desde el /
alias devstart='DC_FILE=docker/docker-compose.yml; sudo docker compose -f $DC_FILE up -d && sudo docker compose -f $DC_FILE exec app bash'
